# Film Draft 3 Implementation Plan (plan 4 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render `video/out/second-look-v3.mp4` (≈2:50, < 3:00), the approved script `video/script-v3.md`, as **one morning, one journey** that a judge or a business owner can follow without effort — plus a subtitle file for YouTube.

**Architecture:** Two stages.
1. **Capture** (`video/capture.mjs`, Playwright): walks the film's path once in a real browser over the running apps (Second Look :8765, Ticketbook :8766) — before/after each click — saving sharp full-page screenshots (device scale 3) and the bounding boxes of every element the film points at (`video/src/captures.json`). It backs up the demo state first and restores it at the end, verified by checksum.
2. **Film** (Remotion): scenes are built from those captures, with a camera (pan/zoom), a **spotlight** (everything dims except the named element), a drawn **cursor** that moves to and clicks the named element, and a **"where you are"** label. Graphic scenes (1, 2, 3, 10) are React cards in the product's own design. Narration from `lines.json` via macOS `say` (Jamie Premium, free); timing from measured audio, as in drafts 1–2.

Why captures instead of draft 2's live `IFrame`: draft 3 shows a *sequence of states* (Marta approves, the ticket updates, Giulia approves). Live pages during a render would need the app to be in several states at once. Captures make the render deterministic and need no server while rendering.

**Tech Stack:** Remotion 4 (already in `video/`), React 18, TypeScript; Playwright from the npx cache (`~/.npm/_npx/361ceb562f3b3235/node_modules/playwright`, Chromium headless shell `~/Library/Caches/ms-playwright/chromium_headless_shell-1234/…` — see HANDOVER gotcha); macOS `say`/`afconvert`.

**Spec:** `docs/specs/2026-10-23-teams-helpdesk-film3-design.md` §4; script `video/script-v3.md` (approved by Claudia 23/10: "ok script"). The script's spoken lines are final: **do not reword them** (pronunciation fixes go in `src/pronounce.json`, never in `lines.json`).

**Rules the film must keep (from the script):** one question per scene; the screen shows only what the voice names; visible cursor for every click; "where you are" label in every app scene; no caption bar (subtitles → `.srt`); no music; Claude not named on screen; no real brand on screen; "made-up" labels stay visible (the app pages already carry them).

### Task 3: Stage pieces — screen, camera, spotlight, cursor, where-label

**Files:** create `video/src/Stage.tsx`; modify `video/src/theme.ts` (`PICTURE_H = HEIGHT`, `BAND_H = 0`)

Components (TypeScript, Remotion):

```tsx
// Coordinates: CSS px of the captured page (laid out 1536 wide). The capture image is 3x.
export type Box = {x: number; y: number; w: number; h: number};
export type Cam = {x: number; y: number; z: number};        // top-left of the view in page px, zoom
export const camOn = (b: Box, z: number, W = 1920, H = 1080): Cam =>  // centre a box at zoom z
  ({x: b.x + b.w / 2 - W / (2 * z), y: b.y + b.h / 2 - H / (2 * z), z});
```

- `Screen({id, cam, to?, from, dur})`: draws `captures/<id>.png` (from `captures.json`) scaled by `cam.z / 3` and translated so `cam` is the top-left; eases to `to` over `dur` frames (same easing as `Page.tsx`). Clamp the camera so the view never leaves the image (no empty edges).
- `Spotlight({box, cam, from, to})`: a full-frame dark veil `rgba(30,41,53,0.55)` with a rounded hole (12px radius, 10px padding) around `box` mapped through `cam`, fading in over 8 frames from `from` and out before `to`. Implement with an SVG mask (rect minus rounded rect).
- `Cursor({path, from})`: a drawn arrow pointer (SVG, ink fill, white 2px outline, 34px tall) that moves along `path: {at: frame, box?: Box, cam: Cam, click?: boolean}[]` — position = centre of `box` mapped through `cam`, eased between points; on `click`, a ring expands and fades (12 frames) and the pointer scales to 0.9 and back. Hidden before the first point.
- `WhereLabel({text, from, to})`: top-left chip, 32px from the edges, white with 1px rule border, `theme.sans` 500 26px, text like "Ticketbook › Ticket #2001"; for Second Look pages "Second Look › Case DEMO-031"; for the live scene the chip is green-bordered "Live · PayPal sandbox". Fades in/out with the scene.
- Mapping helper: `toFrame(b: Box, cam: Cam) => ({x: (b.x - cam.x) * cam.z, y: (b.y - cam.y) * cam.z, w: b.w * cam.z, h: b.h * cam.z})` used by Spotlight and Cursor.
