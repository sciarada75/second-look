# Phone Calls and the Shop's Own Records: Implementation Plan (build step 3, part 1 of 2: "phone")

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phone calls become a channel like email and the web form:
- Sophie's call about order LP-90001 is in the demo, as a recording with two synthetic voices (Kokoro).
- Each call is transcribed on this computer by local whisper when it is installed, else the transcript shipped with the demo is used, labelled so.
- The call is sorted by the caller's number and joins Sophie's case before her email does. Its length is its staff time.
- The morning screen's phone chip counts calls.

The shop's own orders and its courier answer through a read API (`GET /api/orders/<no>`, `GET /api/tracking/<no>`), labelled made-up in the demo. A customer who paid by card has a customer record too.

**Architecture:** A *call box* is a folder where a phone system leaves each recorded call: a `.wav`, a `.json` (caller's number, time, seconds) and, in the demo, a `.txt` transcript. A new module, `secondlook/calls.py`, turns each recording into a request on the channel `"call"`, in exactly the shape `POST /api/requests` files:
- **Transcription:** local whisper runs in its own Python, as a subprocess (offline, never downloads), else the shipped transcript is used.
- **Sorting:** `sort.deterministic` finds the customer by the caller's number, the same way it finds them by an email address. Rules only, no AI call.
- **Filing:** `web.file_calls` files every call in the box once, by its `source_id`. It runs when the demo's case file is first seeded (the call before the emails, as the morning happened) and on every look at the morning screen.

The demo's recording is made once by `demo/make_call.py` with Kokoro (local, free) and committed.

**Tech Stack:** Python 3.9 standard library. Two local, open-weight models live outside the repo, in their own Pythons, and no test runs either:

- whisper: `~/.local/share/whisper/venv/bin/python`, `mlx_whisper`, model `mlx-community/whisper-large-v3-turbo`, already in this Mac's cache.

Tests are plain scripts (`python3 tests/test_x.py`). Every test that imports `web` sets `web.TRANSCRIBE` to a fake.

## Design decisions (made while planning, from what the code and the demo data show)

1. **A call box, not a phone API.** A shop's phone system (a VoIP service, a recorder) can drop each recording in a folder. Second Look reads the folder:
   - the demo's is `demo/calls/`;
   - a live shop sets `SECONDLOOK_CALL_BOX`;
   - with no call box, the morning screen keeps saying "📞 Phone: not connected yet", which is true.

   This also keeps the channel out of `POST /api/requests`. That endpoint still refuses `"call"`, and its message now points at the call box: a call is filed from its recording, never from a typed claim.
2. **Transcription is local or it is shipped, and the case says which.** The order is:
   - local whisper, if `~/.local/share/whisper/venv/bin/python` exists (override: `SECONDLOOK_WHISPER_PYTHON`). The model is read offline (`HF_HUB_OFFLINE=1`), with a 10-minute ceiling, and any failure counts as "no transcript";
   - else the `.txt` beside the recording, labelled "transcript shipped with the demo";
   - else the call waits in the box, unfiled.

   The timeline shows "34 s call · transcript shipped with the demo" or "· transcribed on this computer (local whisper)". On Claudia's Mac whisper is installed, so a fresh run shows whisper's words (about 5 s, offline). A judge's computer shows the shipped ones. The two differ slightly: whisper hears "Order LP 90001", and the transcript ships "order LP-90001". Both sort to the same order.
3. **The recording:** two Kokoro voices, `bf_emma` (Marta, British English) and `af_nicole` (Sophie, American English), five turns, 34 s. It is written at 16 kHz, mono, 16-bit, what whisper reads: 1,096,530 bytes, committed. The script fixes the words, so the shipped transcript never depends on the voice. Kokoro is local and free; Claudia approved running it. No test runs it.
4. **Sorting by number:** a number is its last nine digits ("+39 051 555 0142" = "0515550142"). The customer is the one whose orders carry that number, only when exactly one does: a number on two customers' orders, or on none, goes to a person, as an unknown email address does. Two numbers are added to the demo's own card/bank orders (`other_orders`): Sophie's and Lena's. The PayPal side doesn't move. The fingerprint test, the generator's determinism test and the 12-dispute snapshot prove it (Task 7).
5. **What a call-opened case says:** a call has no subject and two voices. So its line is Second Look's description, "Phone call: says it never arrived", and it is never quoted as the customer's words:
   - the morning screen shows it plain, not as "they wrote: “…”" (`summary_by: "call"`);
   - the case's title is that line too. Sophie's case title changes from her email's subject to it, because her call came first.
6. **A call's length is its staff time** (the spec). `today.month` already counted call minutes (step 2). Now there is one: 0.57 min, so the month's staff cost goes from 57.50 to 57.74 EUR, and the month block names the calls in its estimate.
7. **Orders and courier as a read API.** `GET /api/orders/<no>` and `GET /api/tracking/<no>` give what the case's evidence already reads:
   - in the demo, from `demo/shop.json` (card/bank orders, and PayPal orders whose dispute records hold tracking), each labelled `"source": "…: made-up stand-in (demo shop)"`;
   - on the live shop, PayPal's Transaction Search and tracking API, labelled so.

   They are read-only. No stand-in server was built: these are the same records the case page shows, and a second process would add nothing a judge can check.
8. **Card customers get a record.** `GET /api/customers/<email>` and `/customer/<email>` fall back to the shop's own orders when PayPal has no record: Sophie, 1 order, 64 EUR, "paid by card".

**Not in this plan:** the books, reconciling a refund, PayPal's refund API, live caching (part 2); paid demo-inquiry reviews (Claudia's OK, a later step); the film.

```python
"""Writes the demo shop's one phone call: Sophie (customer) calls Linen & Paper about her tablecloth, and Marta
(customer care assistant) answers. Made up, like everything in the demo shop, and voiced by Kokoro (an open-weight
text-to-speech model) with two voices, so a viewer hears two people.

What it writes, in demo/calls/ (the demo's "call box", as a shop's phone system would leave it):
  2026-10-19-0831-sophie.wav   the recording: 16 kHz, mono, 16-bit (what local transcription reads)
  2026-10-19-0831-sophie.json  what the phone system knows: the caller's number, when, how long
  2026-10-19-0831-sophie.txt   the transcript that ships with the demo, for a computer without local whisper

Run once, with Kokoro's own Python (it lives outside the repo, in ~/.local/share/kokoro):
  ~/.local/share/kokoro/venv/bin/python demo/make_call.py
The words are fixed below, so the transcript never depends on the voice. The recording is committed.
"""
import json
import os
import wave
from pathlib import Path

import numpy as np
from kokoro_onnx import EspeakConfig, Kokoro

HERE = Path(__file__).resolve().parent
NAME = "2026-10-19-0831-sophie"
CALLER = "+39 051 555 0142"           # Sophie's number, as on her order (demo/make_demo.py)
WHEN = "2026-10-19T08:31:00Z"
RATE = 16000
# (who, Kokoro voice, language, words): two clearly different voices, one for each person
LINES = [
    ("Marta", "bf_emma", "en-gb", "Linen and Paper, this is Marta. How can I help?"),
    ("Sophie", "af_nicole", "en-us", "Hello, this is Sophie Durand. I ordered a linen tablecloth, order L P nine zero "
                                     "zero zero one, and it still hasn't arrived. The tracking says delivered, but I "
                                     "have nothing."),
    ("Marta", "bf_emma", "en-gb", "I'm sorry to hear that. Let me look into it, and I'll write to you by email today."),
    ("Sophie", "af_nicole", "en-us", "Thank you. I'll send you an email too, with the order number."),
    ("Marta", "bf_emma", "en-gb", "Perfect. Have a good day, Sophie."),
]
# How the transcript writes what was said (the spoken order number written as the shop writes it)
WRITTEN = {"order L P nine zero zero zero one": "order LP-90001"}


def resample(audio, sr):
    """Kokoro's 24 kHz to 16 kHz, by linear interpolation: plenty for speech."""
    n = int(len(audio) * RATE / sr)
    return np.interp(np.linspace(0, len(audio) - 1, n), np.arange(len(audio)), audio)


def main():
    home = Path(os.environ.get("KOKORO_HOME", os.path.expanduser("~/.local/share/kokoro")))
    k = Kokoro(str(home / "model" / "kokoro-v1.0.onnx"), str(home / "model" / "voices-v1.0.bin"),
               espeak_config=EspeakConfig(data_path=str(home / "espeak-ng-data")))
    pause = np.zeros(int(0.5 * RATE))
    parts, script = [], []
    for who, voice, lang, words in LINES:
        audio, sr = k.create(words, voice=voice, speed=1.0, lang=lang)
        parts += [resample(np.asarray(audio, dtype=np.float64), sr), pause]
        said = words
        for spoken, written in WRITTEN.items():
            said = said.replace(spoken, written)
        script.append(f"{who}: {said}")
    audio = np.concatenate(parts)
    pcm = (np.clip(audio, -1, 1) * 32767).astype("<i2")
    (HERE / "calls").mkdir(exist_ok=True)
    with wave.open(str(HERE / "calls" / f"{NAME}.wav"), "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(RATE)
        w.writeframes(pcm.tobytes())
    seconds = round(len(pcm) / RATE)
    (HERE / "calls" / f"{NAME}.json").write_text(json.dumps(
        {"_comment": "Demo shop, made up: what the shop's phone system knows about one call. Written by demo/make_call.py.",
         "recording": f"{NAME}.wav", "from_phone": CALLER, "time": WHEN, "seconds": seconds}, indent=1) + "\n")
    (HERE / "calls" / f"{NAME}.txt").write_text("\n".join(script) + "\n")
    print(f"{NAME}.wav: {seconds} s, {len(pcm) * 2 // 1024} KB")


if __name__ == "__main__":
    main()
```

```python
"""The call box: a folder where the shop's phone system leaves its recorded calls. Each call is a recording (.wav)
and what the phone system knows about it (.json: the caller's number, when, how many seconds). The demo's call box
is demo/calls/; a shop points SECONDLOOK_CALL_BOX at its own.

Second Look turns each new recording into a request on the channel "call": it transcribes the recording on this
computer with local whisper (an open-weight speech-to-text model, if it is installed: nothing leaves the machine),
or, when it isn't, uses the transcript that ships beside the recording (.txt), labelled so. Without either, the call
waits. A call's length is its staff time. Nothing here calls a paid service.
"""
from __future__ import annotations

import json
import os
import subprocess
from pathlib import Path

# Local whisper runs in its own Python (it needs packages Second Look doesn't): set SECONDLOOK_WHISPER_PYTHON to
# another one. The model is read from this computer's cache only (HF_HUB_OFFLINE): never downloaded mid-call.
WHISPER_PYTHON = Path(os.environ.get("SECONDLOOK_WHISPER_PYTHON",
                                     "~/.local/share/whisper/venv/bin/python")).expanduser()
WHISPER_MODEL = "mlx-community/whisper-large-v3-turbo"
_WHISPER = ("import sys, wave, numpy as np, mlx_whisper\n"
            "w = wave.open(sys.argv[1])\n"
            "a = np.frombuffer(w.readframes(w.getnframes()), dtype='<i2').astype(np.float32) / 32768\n"
            "print(mlx_whisper.transcribe(a, path_or_hf_repo=sys.argv[2], language='en')['text'].strip())\n")
SHIPPED = "transcript shipped with the demo"
WHISPERED = "transcribed on this computer (local whisper)"


def recordings(box: Path | None) -> list:
    """Every call in the box, oldest first: {source_id, wav, txt, from_phone, time, seconds}. A call whose recording
    or record is missing or unreadable is skipped, never guessed."""
    if not box or not Path(box).is_dir():
        return []
    out = []
    for meta in sorted(Path(box).glob("*.json")):
        try:
            m = json.loads(meta.read_text())
        except (OSError, ValueError):
            continue
        wav = meta.with_name(str(m.get("recording") or meta.stem + ".wav"))
        if not isinstance(m, dict) or not wav.is_file() or not m.get("from_phone") or not m.get("time"):
            continue
        seconds = m.get("seconds")
        out.append({"source_id": f"callbox:{meta.stem}", "wav": wav, "txt": meta.with_suffix(".txt"),
                    "from_phone": str(m["from_phone"]), "time": str(m["time"]),
                    "seconds": float(seconds) if isinstance(seconds, (int, float)) and seconds > 0 else 0.0})
    return sorted(out, key=lambda r: r["time"])


def whisper(wav: Path, run=subprocess.run) -> str | None:
    """The recording's words by local whisper, or None when it isn't installed, fails or hears nothing."""
    if not WHISPER_PYTHON.is_file():
        return None
    try:
        r = run([str(WHISPER_PYTHON), "-c", _WHISPER, str(wav), WHISPER_MODEL], capture_output=True, text=True,
                timeout=600, env={**os.environ, "HF_HUB_OFFLINE": "1"})
    except (OSError, subprocess.SubprocessError):
        return None
    text = (r.stdout or "").strip() if r.returncode == 0 else ""
    return text or None


def transcript(rec: dict, transcribe=whisper) -> tuple:
    """(words, how): local whisper first, else the transcript shipped beside the recording, else (None, None)."""
    text = transcribe(rec["wav"])
    if text:
        return text, WHISPERED
    try:
        shipped = rec["txt"].read_text().strip()
    except OSError:
        shipped = ""
    return (shipped, SHIPPED) if shipped else (None, None)


def as_request(rec: dict, transcribe=whisper) -> dict | None:
    """A call as a request, the shape POST /api/requests files: channel "call", the caller's number instead of an
    address, its transcript as the text, and its length in minutes (its staff time). None: no words to file yet."""
    text, how = transcript(rec, transcribe)
    if not text:
        return None
    return {"channel": "call", "from": {"name": None, "email": None, "phone": rec["from_phone"]}, "time": rec["time"],
            "subject": "Phone call", "text": text, "source_id": rec["source_id"],
            "minutes": round(rec["seconds"] / 60, 2), "transcript": how, "recording": rec["wav"].name}
```

```python
            "source": f"Courier: {STAND_IN}" if src == "demo" else "Courier: PayPal tracking"}


def own_customer(key: str, src: str) -> dict | None:
    """A customer who paid the shop directly (card, bank) has no PayPal record: their record from the shop's own
    orders, in the shape the customer API gives for a PayPal customer. None when the shop has no such order."""
    k = (key or "").strip().lower()
    mine = [o for o in shop_orders(src) if not o.get("transaction_id") and (o.get("email") or "").strip().lower() == k]
    if not k or not mine:
        return None
    return {"payer_id": None, "name": mine[-1].get("name"), "email": mine[0].get("email"), "orders": len(mine),
            "spent": round(sum(_num(o.get("amount")) or 0 for o in mine), 2),
            "first_order": min(o.get("date") or "" for o in mine), "last_order": max(o.get("date") or "" for o in mine),
            "paid_with": sorted({str(o.get("paid_with") or "card") for o in mine}), "disputes": [], "escalated": 0,
            "refunded": 0.0, "dispute_rate": None, "shop_dispute_rate": None, "times_shop_rate": None,
            "escalations": "No PayPal disputes: paid the shop directly."}
```
