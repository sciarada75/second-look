# The Books and PayPal's Refund API: Implementation Plan (build step 3, part 2 of 2: "books")

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every money event reaches the shop's accounting (Decision 5).
- **Live:** each event goes as it happens to a bookkeeping stand-in, *Bookbox*: one page, made up, labelled so.
- **Monthly:** a CSV for the month (`/books.csv?month=YYYY-MM`). Each row has the order and invoice number, amount, fees, whether the item came back or was lost, the date, who approved it and the channel. It is the facts only, never a credit note.
- **Export:** the morning screen's *I know* block gets *Export for accounting*.
- **Reconcile:** a person marks a logged refund *paid* (card, bank or PayPal) or *cancelled*:
  - cancelled lifts the money holds (guard rules 9 and 10) for that amount;
  - paid keeps them, and lets a later PayPal dispute on that order be defended with the refund as proof.
- **PayPal's refund API:** a refund on an inquiry about an order paid through PayPal goes back through `POST /v2/payments/captures/{capture_id}/refund`. The demo logs it; the live sandbox's first one waits for Claudia's OK (Task 11).
- **Live caching:** the live shop's orders and disputes (about 50 PayPal calls a page) are read once a minute, not on every page.

**Architecture:**
- A new pure module, `secondlook/books.py`, turns a case's money entries and PayPal's resolved disputes into rows of the books (`case_events`, `dispute_events`), with `for_month` and `csv_text`. Nothing in it calls PayPal or a model.
- `web.py` gathers the rows (`books_rows`) and posts each new event to `SECONDLOOK_BOOKS_URL` (`post_books`), as `notify` posts to the helpdesk: a failure is logged, never blocking.
- A refund's later state is a `status` on its money entry (`logged`, `sent to PayPal`, `paid`, `cancelled`), set once by `reconcile`. Every place that counts money skips `cancelled`. A dispute's records carry `refund_paid` when every refund on its order is marked paid; guard rule 10 then lets DEFEND through, and `execute` submits `PROOF_OF_REFUND`.
- `PayPalDisputes.refund_capture` / `get_capture` call Payments v2; `MockPayPal.refund_capture` logs. The Outbox calls it for an order with a PayPal transaction, before anything is recorded.
- Bookbox (`bookbox/`) is a second small app, the same pattern as Ticketbook: JSON only, an optional shared key, every string escaped.

**Tech Stack:** Python 3.9 standard library. Tests are plain scripts (`python3 tests/test_x.py`). No test calls a model or PayPal: the demo's PayPal logs, and the live client's `_call` is faked.

**Spec:** `docs/specs/2026-10-25-inquiry-system-design.md`, Decision 5 and build step 3: "accounting (live stand-in + CSV), PayPal refund API for PayPal-paid inquiries". Part 1 (`docs/plans/2026-10-25-phone.md`) must be merged first: this plan starts from main with `tests/test_calls.py` (291 tests).

## Design decisions (made while planning, from what the code and the demo data show)

1. **The books' rows.**
   - **Columns:** `date, kind, order_no, invoice_no, amount, currency, fees, item, approved_by, channel, case_id, dispute_id, status`.
   - **Kinds:** refund, partial refund, replacement, fee (from a case); PayPal refund, PayPal fee (from a resolved dispute).
   - **The item:**
     - "back at the shop": a return delivered to the shop, or a refund asked for after a return;
     - "lost": not received, and the courier never delivered it;
     - "with the customer": delivered, or kept on an exchange or not-as-described;
     - else "not known".
   - **The channel:** the one the answer went out on.
   - **A PayPal dispute's fee:** estimated from PayPal's fee table, exactly as the Overview does. The CSV says `fees`, and the README says it is estimated.
   - **No credit note,** ever: that is the accountant's.
2. **Invoice numbers.** The shop's own when its order carries `invoice_no`. In the demo they are made up from the order's digits (`LP-INV-90001`, `LP-INV-00001`), stated in the README. A live PayPal order carries none, so the column is empty and the accounting system matches by order number.
3. **Live and monthly are the same facts.**
   - **Live:** each event Second Look causes is posted when it happens, `"event": "money"` plus the row: a refund logged or sent to PayPal, a replacement, a refund marked paid or cancelled, and a refund or offer on a PayPal dispute.
   - **Monthly:** the CSV is rebuilt from the cases and PayPal's resolved disputes, so it holds the demo's earlier cases too. A PayPal dispute appears in the CSV once PayPal resolves it, with PayPal's outcome. Until then it is only in the live feed, as "sent to PayPal".
4. **Reconcile, once.** `reconcile(case, refund's index, "paid"|"cancelled", paid_with, by)` changes `logged` or `sent to PayPal` to `paid` (with `card`, `bank` or `paypal`) or `cancelled`. It also notes it on the timeline and posts the new row to the books.
   - **Once only:** a second mark is refused (409), because what the books were told is never rewritten.
   - **Who:** only a refund can be marked, by a named person of the shop.
   - **The effects:**
     - *Cancelled:* the refund counts nowhere (rule 9's total on the order, rule 10's dispute note, the case's money moved, the month's money given back, what is left to give), so its holds lift by that amount.
     - *Paid:* it still counts (money went back, once), and the order's disputes get `refund_paid`.
     - *Rule 10:* still holds a refund or an offer, but lets DEFEND through, and `execute` submits the refund as `PROOF_OF_REFUND`, not proof of delivery.
     - *A partial mark* (some refunds paid, some not) is not proof: every non-cancelled refund must be paid.
5. **Which refunds go to PayPal.** An inquiry's refund on an order with a PayPal transaction id goes through `refund_capture(transaction id, amount, currency, the reply as note_to_payer)`, before the case records it, so a refused refund is never logged as done. In the demo, the demo's PayPal logs `capture-refund` in `.tmp/demo-paypal-actions.jsonl`. A card or bank order is logged "for your payment provider (not connected)", and a person marks it paid later.

   A refund PayPal accepted is still `sent to PayPal`, not `paid`, until a person marks it: the conservative choice, and the same one step for every payment method.
6. **The capture id** is the order's PayPal transaction id: Transaction Search's `transaction_id`, and a dispute's `seller_transaction_id`. PayPal's docs give this for Checkout orders, but it is not yet checked on this sandbox: Task 11 checks it read-only (`get_capture`) before the one live refund. A capture under an open dispute may be held by PayPal; Second Look never refunds an inquiry whose order has a PayPal dispute (it is answered on the dispute; step 1's refusal).
7. **Live caching:** the live shop's orders and disputes are kept 60 s (`LIVE_TTL`), for `/today`, `/overview`, the customer pages and every reader of `shop_orders` and `shop_disputes`. Any answer sent on a non-demo case clears it (`_live_forget`), so a page after an approval reads PayPal afresh. A failed read is never cached. The demo is a file, read once already.
8. **Bookbox, not a real product's name.** It listens on 127.0.0.1:8767, takes `POST /hooks/secondlook` (JSON only, 415 otherwise; with `BOOKBOX_HOOK_KEY`, 403 without `?key=`) and shows what it received on `/`, newest first. It keeps it in `.tmp/bookbox-received.jsonl`.

**Not in this plan:** paying out by card or bank (the payment provider isn't connected; a person marks it paid), a credit note, an API route for reconcile (the case page's form only), the film.

```python
"""The books: every money event of the shop's cases and PayPal disputes, as the shop's accounting needs the facts.

Decision 5: accounting gets the facts, never the credit note. Each event says what happened to money or goods,
for which order and invoice, how much, any fee, whether the item came back or was lost, when, who approved it and
on which channel. The credit note is a legal document the accounting system or the accountant makes from these.

Two ways out: each event Second Look itself causes goes live to the shop's bookkeeping (web.post_books, to
SECONDLOOK_BOOKS_URL), and every month's events, PayPal's own outcomes included, export as one CSV. Pure code:
nothing here calls PayPal or a model.
"""
from __future__ import annotations

import csv
import io

from . import ledger
from .costs import DISPUTE_FEE, escalated

COLUMNS = ["date", "kind", "order_no", "invoice_no", "amount", "currency", "fees", "item", "approved_by", "channel",
           "case_id", "dispute_id", "status"]
KIND = {"refund": "refund", "partial_refund": "partial refund", "replace": "replacement", "fee": "fee"}
# What happened to the item: back at the shop, lost on the way, with the customer, or not known.
BACK, LOST, KEPT, UNKNOWN = "back at the shop", "lost", "with the customer", "not known"


def item_state(kind: str | None, order: dict | None) -> str:
    """Where the item is, from the courier's record of the order and what the case is about."""
    o = order or {}
    ret = o.get("return") or {}
    if ret.get("status") == "DELIVERED" and "shop" in str(ret.get("delivered_to") or "shop").lower():
        return BACK
    if kind == "refund_missing":
        return BACK                                    # the customer returned it: that is what the refund is for
    if kind == "not_received":
        return KEPT if (o.get("tracking") or {}).get("status") == "DELIVERED" else LOST
    return KEPT if kind in ("not_as_described", "wrong_size") else UNKNOWN


def _channel_at(c: dict, at: str) -> str:
    """The channel the shop's answer went out on when the money moved: the "out" entry of that minute, else the
    channel the customer last used before it."""
    out = [x for x in c.get("timeline", []) if x.get("direction") == "out" and x.get("at") == at]
    if out:
        return out[-1].get("channel") or ""
    ins = [x for x in c.get("timeline", []) if x.get("direction") == "in" and (x.get("at") or "") <= (at or "")]
    return ins[-1]["channel"] if ins else ""


def case_events(c: dict, order: dict | None, invoice: str | None, currency: str = "EUR") -> list:
    """The money events one case logged: refunds, partial refunds, replacements, fees, each as a row of the books."""
    rows = []
    for m in c.get("money", []):
        kind = KIND.get(m.get("kind"))
        if not kind:
            continue
        rows.append({"date": m.get("at") or "", "kind": kind, "order_no": c.get("order_no") or "", "invoice_no": invoice or "",
                     "amount": round(float(m.get("amount") or 0), 2), "currency": (order or {}).get("currency") or currency,
                     "fees": 0.0, "item": item_state(c["problem"].get("kind"), order) if kind != "fee" else "",
                     "approved_by": m.get("by") or "", "channel": _channel_at(c, m.get("at") or ""),
                     "case_id": c.get("id") or "", "dispute_id": c.get("dispute_id") or "",
                     "status": m.get("status") or "logged"})
    return rows


def dispute_events(d: dict, invoice: str | None, handled_by: str | None, high_volume: bool) -> list:
    """What a resolved PayPal dispute moved: PayPal's refund to the buyer and the dispute fee, from PayPal's outcome
    (the fee estimated from PayPal's fee table, as the Overview estimates it)."""
    if d.get("status") != "RESOLVED":
        return []
    cur = d["dispute_amount"].get("currency_code", "EUR")
    standard, hv = DISPUTE_FEE.get(cur, (0.0, 0.0))
    fee = (hv if high_volume else standard if ledger.outcome(d) in ("lost_claim", "lost_no_reply") else 0.0) \
        if escalated(d) else 0.0
    back = ledger.refunded(d)
    if not back and not fee:
        return []
    tx = ((d.get("disputed_transactions") or [{}])[0]).get("seller_transaction_id") or ""
    item = {"MERCHANDISE_OR_SERVICE_NOT_RECEIVED": LOST, "CREDIT_NOT_PROCESSED": BACK}.get(d.get("reason"), UNKNOWN)
    return [{"date": (d.get("update_time") or d.get("create_time") or "")[:16], "kind": "PayPal refund" if back else "PayPal fee",
             "order_no": tx, "invoice_no": invoice or "", "amount": round(back, 2), "currency": cur, "fees": round(fee, 2),
             "item": item if back else "", "approved_by": handled_by or "", "channel": "paypal", "case_id": "",
             "dispute_id": d["dispute_id"], "status": ledger.OUTCOME_LABEL.get(ledger.outcome(d), "resolved")}]


def for_month(rows: list, month: str) -> list:
    """The rows of one month ("2026-10"), oldest first."""
    return sorted((r for r in rows if str(r["date"]).startswith(month)), key=lambda r: (r["date"], r["kind"]))


def csv_text(rows: list) -> str:
    out = io.StringIO()
    w = csv.DictWriter(out, fieldnames=COLUMNS, extrasaction="ignore", lineterminator="\n")
    w.writeheader()
    for r in rows:
        w.writerow({**r, "amount": f'{r["amount"]:.2f}', "fees": f'{r["fees"]:.2f}'})
    return out.getvalue()
```

```python
def test_bookbox_hears_only_second_look_s_json_and_with_a_key_only_its_key():
    box = bookbox.Bookbox(Path(tempfile.mkdtemp()) / "r.jsonl")
    handler = type("H", (bookbox.Handler,), {"box": box})
    srv = ThreadingHTTPServer(("127.0.0.1", 0), handler)
    threading.Thread(target=srv.serve_forever, daemon=True).start()
    try:
        def post(body, ctype="application/json", path="/hooks/secondlook"):
            con = HTTPConnection("127.0.0.1", srv.server_address[1], timeout=5)
            con.request("POST", path, body=body, headers={"Content-Type": ctype})
            return con.getresponse().status
        assert post('{"event": "money", "kind": "refund"}') == 204 and post("x", "text/plain") == 415
        assert post("{nope") == 400
        os.environ["BOOKBOX_HOOK_KEY"] = "k1"
        try:
            assert post('{"event": "money", "kind": "refund"}') == 403
            assert post('{"event": "money", "kind": "refund"}', path="/hooks/secondlook?key=k1") == 204
        finally:
            del os.environ["BOOKBOX_HOOK_KEY"]
        assert len(box.received()) == 2 and box.received()[0]["kind"] == "refund"
    finally:
        srv.shutdown()
```

```python
"""Bookbox, a made-up bookkeeping stand-in: what a shop's accounting system would receive from Second Look.

Bookbox is NOT a real product and imitates none. It shows the seam Decision 5 describes: Second Look sends the
facts of every money event it causes (refund logged, refund paid or cancelled, replacement, refund through PayPal),
live, as JSON to one address; the accounting system books them. Bookbox only keeps them and shows them on one page.
It never makes a credit note: that is the accountant's.

Every string it shows is HTML-escaped. Run:  python3 -m bookbox serve   ->  http://127.0.0.1:8767
Second Look sends here when started with SECONDLOOK_BOOKS_URL=http://127.0.0.1:8767/hooks/secondlook
"""

import html
import json
import os
import threading
from datetime import datetime, timezone
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

from urllib.parse import parse_qs, urlparse

e = html.escape
FIELDS = ["date", "kind", "order_no", "invoice_no", "amount", "currency", "fees", "item", "approved_by", "channel",
          "case_id", "dispute_id", "status"]
HEADS = {"date": "Date", "kind": "What", "order_no": "Order", "invoice_no": "Invoice", "amount": "Amount", "currency": "",
         "fees": "Fees", "item": "Item", "approved_by": "Approved by", "channel": "Channel", "case_id": "Case",
         "dispute_id": "PayPal dispute", "status": "Status"}


class Bookbox:
    def __init__(self, path):
        self.path = Path(path)
        self._lock = threading.Lock()

    def add(self, payload) -> bool:
        """Keep one money event (one JSON line), with the time it arrived. Anything that isn't one is ignored."""
        if not (isinstance(payload, dict) and payload.get("event") == "money" and isinstance(payload.get("kind"), str)):
            return False
        line = {k: payload.get(k) for k in FIELDS} | {"received": datetime.now(timezone.utc).isoformat(timespec="seconds")}
        with self._lock:
            self.path.parent.mkdir(parents=True, exist_ok=True)
            with open(self.path, "a", encoding="utf-8") as f:
                f.write(json.dumps(line, ensure_ascii=False, default=str) + "\n")
        return True

    def received(self) -> list:
        try:
            lines = self.path.read_text(encoding="utf-8").splitlines()
        except OSError:
            return []
        out = []
        for line in lines:
            try:
                x = json.loads(line)
            except ValueError:
                continue
            if isinstance(x, dict):
                out.append(x)
        return out

    def page(self) -> str:
        rows = "".join("<tr>" + "".join(f"<td>{e(str(x.get(k) if x.get(k) is not None else ''))}</td>" for k in FIELDS)
                       + "</tr>" for x in reversed(self.received()))
        head = "".join(f"<th>{e(HEADS[k])}</th>" for k in FIELDS)
        return f"""<!doctype html><html lang="en"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1"><title>Bookbox</title>
<style>body{{margin:0;font:400 15px/1.5 Georgia,serif;background:#FBF8F1;color:#2B2A26}}
header{{padding:16px 28px;background:#2F4A3A;color:#F3EFE2}} header b{{font-size:20px}} header small{{display:block;opacity:.8}}
main{{padding:22px 28px}} table{{border-collapse:collapse;width:100%;background:#fff}}
th,td{{text-align:left;padding:7px 9px;border-bottom:1px solid #E2DccC;font-size:14px}} th{{background:#EFE9D9}}
.note{{color:#6B675C;max-width:70ch}}</style></head><body>
<header><b>Bookbox</b><small>a made-up bookkeeping stand-in, not a real product</small></header>
<main><h1>What Bookbox received from Second Look</h1>
<p class="note">Each line is one money event Second Look sent, newest first: the facts the books need. Bookbox makes no
credit note; that is the accountant's.</p>
<table><thead><tr>{head}</tr></thead><tbody>{rows or '<tr><td colspan="13">Nothing received yet.</td></tr>'}</tbody></table>
</main></body></html>"""


class Handler(BaseHTTPRequestHandler):
    box: Bookbox = None  # set by serve()

    def _send(self, body: str, code: int = 200, ctype: str = "text/html; charset=utf-8"):
        b = body.encode()
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

    def do_GET(self):
        if urlparse(self.path).path == "/":
            return self._send(self.box.page())
        self._send("Not found", 404, "text/plain; charset=utf-8")

    def do_POST(self):
        u = urlparse(self.path)
        raw = self.rfile.read(min(int(self.headers.get("Content-Length") or 0), 100_000))
        if u.path != "/hooks/secondlook":
            return self._send("Not found", 404, "text/plain; charset=utf-8")
        key = os.environ.get("BOOKBOX_HOOK_KEY")   # with a key set, Second Look's address must carry ?key=<it>
        if key and not hmac.compare_digest((parse_qs(u.query).get("key") or [""])[0].encode(), key.encode()):
            return self._send("Wrong or missing key.", 403, "text/plain; charset=utf-8")
        if (self.headers.get("Content-Type") or "").split(";")[0].strip().lower() != "application/json":
            return self._send("Send JSON (Content-Type: application/json).", 415, "text/plain; charset=utf-8")
        try:
            payload = json.loads(raw or b"null")
        except ValueError:
            return self._send("Not JSON", 400, "text/plain; charset=utf-8")
        self.box.add(payload)
        self.send_response(204)
        self.end_headers()

    def log_message(self, *args):  # quiet terminal
        pass


def serve(port: int = 8767) -> None:
    Handler.box = Bookbox(ROOT / ".tmp" / "bookbox-received.jsonl")
    print(f"Bookbox: http://127.0.0.1:{port}", flush=True)
    ThreadingHTTPServer(("127.0.0.1", port), Handler).serve_forever()
```

```python
    """Second Look -> the shop's bookkeeping: POST one money event as JSON to SECONDLOOK_BOOKS_URL (Bookbox in the demo,
```
